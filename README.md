# AtCoder Solutions

This repository contains my solutions to problems I have attempted on [AtCoder](https://atcoder.jp/).

The main purpose of this repository is to keep track of the problems I solve, the approaches I try, and the reasoning behind my solutions.

## Repository Structure

The problems are divided into two main folders:

- **Participated** — Contests in which I participated.
- **NonParticipated** — Contests that I did not participate in but attempted the problems from.

Each folder is further organized by contest:

```text
AtCoder/
├── Participated/
│   ├── ABCXXX/
│   │   ├── question.md
│   │   ├── thinking.md
│   │   ├── solution.py
│   │   └── solution.cpp
│   └── ABCYYY/
│       ├── question.md
│       ├── thinking.md
│       └── solution.py
│
└── NonParticipated/
    ├── ABCZZZ/
    │   ├── question.md
    │   ├── thinking.md
    │   └── solution.cpp
    └── ABCWWW/
        ├── question.md
        ├── thinking.md
        ├── solution.py
        └── solution.cpp
```

## Files Inside Each Contest

Each contest folder contains information about the problems I attempted during that contest.

### `question.md`

Contains the problem statement and relevant information about the problem.

### `thinking.md`

Contains my thought process while reading and solving the problem, including:

- Initial observations
- Ideas and approaches I considered
- Different approaches I tried
- Mistakes or dead ends
- The reasoning behind my final approach

This file is meant to capture **how I thought about the problem**, rather than simply explaining the final solution.

### `solution.py` / `solution.cpp`

Contains the solution implemented in Python or C++.

I use whichever language feels more natural for a particular problem. Some problems may have only one implementation, while others may contain solutions in **both Python and C++**.

When both implementations are present, they may represent the same approach translated into another language or different approaches to solving the same problem.

The solution files include the **time and space complexity** in comments at the top.

Example:

```cpp
// Time Complexity: O(N log N)
// Space Complexity: O(N)
```

## Goal

The goal of this repository is not just to store accepted solutions, but to create a record of my competitive programming journey.

By keeping my questions, thought process, and implementations together, I can revisit problems later and understand not only **what solution worked**, but also **how I approached the problem and where I went wrong**.
